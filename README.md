# svc-stats

Микросервис для хранения и получения статистики игроков.

Поддерживает создание, обновление и получение статистики игроков, а также выдачу рейтингов с сортировкой и пагинацией.

## Возможности

* Создание статистики игрока
* Обновление статистики игрока
* Получение статистики по ID игрока
* Получение таблицы лидеров
* Сортировка по различным параметрам
* Пагинация результатов
* Проверка состояния сервиса

---

## Требования

* Python 3.10+
* Docker и Docker Compose (для быстрого запуска БД)

---

## Быстрый запуск

### 1. Запуск PostgreSQL

```bash
docker-compose up -d
```

Проверьте, что контейнер успешно запущен:

```bash
docker ps
```

---

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

---

### 3. Запуск сервиса

```bash
python main.py
```

После запуска сервис будет доступен по адресу:

```text
http://127.0.0.1:9005
```

---

## API

### Проверка работоспособности

#### GET /live

Проверка состояния сервиса.

**Пример запроса**

```http
GET /live
```

---

### Работа со статистикой

#### POST /stats/{user_id}

Создание новой статистики игрока.

**Пример**

```http
POST /stats/123
```

---

#### PUT /stats/{user_id}

Обновление статистики существующего игрока.

**Пример**

```http
PUT /stats/123
```

---

#### GET /stats/{user_id}

Получение статистики игрока.

**Пример**

```http
GET /stats/123
```

---

### Таблица лидеров

#### GET /stats

Получение списка игроков с сортировкой и пагинацией.

**Параметры запроса**

| Параметр | Описание                       |
| -------- | ------------------------------ |
| sort     | Поле сортировки                |
| page     | Номер страницы                 |
| pageSize | Количество записей на странице |

**Пример**

```http
GET /stats?sort=kills&page=1&pageSize=20
```

---

## Доступные варианты сортировки

| Поле        | Описание           |
| ----------- | ------------------ |
| kills       | Количество убийств |
| deaths      | Количество смертей |
| time_played | Время в игре       |

---

## Пример использования

Получить первую страницу рейтинга по количеству убийств:

```http
GET /stats?sort=kills&page=1&pageSize=20
```

Получить статистику игрока:

```http
GET /stats/123
```
